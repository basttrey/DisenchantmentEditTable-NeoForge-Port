# Disenchantment Edit Table — NeoForge Port

Unofficial port of Disenchantment Edit Table 1.2.0, originally created by ji_GGO.

Original project:
https://www.curseforge.com/minecraft/mc-mods/disenchantment-edit-table

Original license: LGPLv3

This port is not affiliated with, endorsed by, or officially maintained by the original author.

## Changes

- Ported from Forge 1.20.2 to NeoForge 1.21.
- Updated enchantment handling to the Minecraft 1.21 Holder and ItemEnchantments system.
- Updated ItemStack and Data Components support.
- Migrated networking to NeoForge custom payloads and StreamCodec.
- Updated registries, blocks, block entities, menus, and GUI code.
- Updated recipes, loot tables, advancements, and tags.
- Restored the original animated book, GUI buttons, and page-turn sounds.
- Replaced the old Nashorn cost-expression implementation.
